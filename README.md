# 🎬 Filmes App

Aplicativo mobile desenvolvido em React Native com Expo que consome dados da API pública TVMaze para realizar sorteios aleatórios de filmes/séries e exibir suas informações na tela.

---

# 📱 Funcionalidades

- Consumo de API pública
- Sorteio aleatório de filmes/séries
- Exibição de imagem do filme
- Exibição de nota
- Exibição de linguagem
- Exibição de gêneros
- Interface estilizada em tema escuro
- Logo personalizada

---

# 🚀 Tecnologias utilizadas

- React Native
- Expo
- JavaScript
- API TVMaze

---

# 🌐 API utilizada

TVMaze API:

https://api.tvmaze.com/shows

# ▶️ Como executar o projeto

```bash

```
 
---
 
## 2. Entrar na pasta do projeto
 
```bash
cd Filmes-App
```
 
---
 
## 3. Instalar dependências
 
```bash
npm install
```
 
---
 
## 4. Executar o projeto
 
```bash
npx expo start
```
